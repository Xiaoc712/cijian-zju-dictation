# 词间默写 · 微信小程序版

给浙大学生服务的大英背诵与默写工具，版本 1.0.2，含三册 2616 个词条。默认本机保存，无需登录或开通云开发；手机和平板分别保存，通过 JSON 备份迁移。

## 功能

- 四个入口：背诵、默写、生词、我的；熟词库和深浅模式位于“我的”。
- 背诵支持显示中文、显示英文、中英显示；点击先揭示，后续每次点击标记加一，同英文不同中文卡片分别计数。
- 右滑展开“标记-1／生词／斩”，左滑关闭；标记最低0，斩词后不出现在背诵或默写。
- 顺序、乱序、标记从多到少排序；同标记随机，增减和批量清零保持当前顺序，重新选择标记排序才重排。
- “清除标记”确认后清零当前单元全部未斩词条，包括尚未加载的词条；其他单元及熟词保留。
- 英文下方显示离线音标，短语不显示；1813个独立单词覆盖1807个，未收录专名不猜测。来源及许可见 third-party/音标说明.md。
- 默写忽略大小写及空白；什么都不输入也可点“提交”，计错并加入生词。支持回退、跳过、首字母、例句、重试及斩词撤销。
- 答对／答错不同本地音效，支持开关、加载失败恢复与系统静音；蓝紫色主题提供白色浅色、黑灰深色两套配色。
- 学习记录及备份，旧标记缓存迁移，键盘避让、列表自动加载及底部留白。
- 好友分享代码已配置；实际能力由微信账号状态及平台规则决定。英文卡片点读尚未接入。

## 导入及检查

1. 微信开发者工具导入本目录；入口为 pages/study/index。
2. 学习者可使用已发布小程序；自行开发请将 project.config.json 的 AppID 替换为自己的小程序 AppID。
3. 点击编译／预览，无需 npm 构建、服务器或云开发。
4. 仅在自行选择开启云同步时配置云环境及 cloudfunctions/studySync；默认关闭。

```powershell
node --test tests/*.test.cjs
node scripts/validate.cjs
```

核心已提交可运行的 JS。修改 shared/learning.ts 后，在本目录执行 `npm install` 和 `npm run generate` 重新生成客户端／云函数核心。原词条及ID保留；音标和图标重建脚本位于 scripts，原始字典及构建工具只放 outputs，不上传。

运行图片与音频总计90,947字节，验证器要求资源合计低于200KB。清理小程序数据会删除本机学习记录，请先导出备份。
